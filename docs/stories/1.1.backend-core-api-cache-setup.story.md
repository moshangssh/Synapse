# Story 1.1: Backend - Core API & Cache Setup

## Status
Ready for Review

## Story
**As a** developer,
**I want** a robust backend service to handle AI optimization requests, manage caching, and communicate with external LLMs,
**so that** I can provide a stable and reliable foundation for frontend functionality.

## Acceptance Criteria
1. Create a new FastAPI route `POST /api/v1/optimizer/optimize` that can receive subtitle lists and optional reference information.
2. Implement subtitle batch processing (FR2) and parallel processing (FR3).
3. Build correct JSON input and system prompts according to `2.4 Prompt Engineering Guidelines` (FR4, FR9).
4. Implement calls to user-configured external LLM APIs.
5. Implement in-memory caching mechanism (FR5).
6. Have complete error handling for external API calls and return clear error information to frontend (NFR2).
