# Story 1.2: Backend - Subtitle Alignment Logic

## Status
Ready for Done

## Priority
High

## Estimate
5 story points

## Story
**As a** user,
**I want** AI-optimized text to be perfectly aligned with my original subtitles,
**so that** no timecodes or subtitle entries are lost or out of order.

## Acceptance Criteria
1. Create a `SubtitleAligner` component (FR6).
2. The component should accurately recombine optimized text with original subtitle IDs and timecodes, achieving 100% preservation of original metadata and maintaining correct sequential order.
3. If AI returns subtitle count that doesn't match input, process should fail gracefully and report error within 100ms.
4. After successful alignment, output a structurally complete subtitle list with all required fields (id, startTimecode, endTimecode, text, diffs).
