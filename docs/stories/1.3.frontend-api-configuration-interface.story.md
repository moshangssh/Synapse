# Story 1.3: Frontend - API Configuration Interface

## Status
Ready for Review

## Priority
High

## Estimate
3 story points

## Story
**As a** user,
**I want** a settings interface to configure my AI service API key and endpoint address,
**so that** the application can connect to my chosen service.

## Acceptance Criteria
1. Add a new settings entry in the UI with a settings modal window.
2. The window contains "API Endpoint URL" and "API Key" (password type) input fields.
3. "Save" button can securely store the information in user local storage (NFR1).
4. "Test Connection" button can verify credential validity and provide feedback.
