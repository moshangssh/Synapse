# Story 1.5: Frontend - Result Review and Application

## Status
Ready for Review

## Priority
High

## Estimate
3 story points

## Story
**As a** user,
**I want** to review all changes before applying AI modifications,
**so that** I can have complete control over the final subtitle content.

## Acceptance Criteria
1. 优化成功后，弹出一个"结果审阅"模态窗口。
2. 窗口中只显示被修改过的字幕。
3. 使用 `DiffHighlighter.tsx` 组件高亮展示差异。
4. 提供"全部应用"和"取消"按钮，功能符合预期。
5. 如果后端返回错误，则显示错误通知 (NFR2)。
